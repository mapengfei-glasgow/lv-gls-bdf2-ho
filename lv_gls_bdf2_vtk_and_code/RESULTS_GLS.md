# GLS 移植试验：实际运行结果

已在此前 Miniconda / DOLFINx 0.11.0 环境中运行。
本次结果使用上传的 GLS 两项和 tau 公式、P1/P1 速度—压力、首步 BE 后 BDF2。
保留 LV 动态惯性、材料黏性、主动应力及原有边界条件；没有加入上一版增强体积项。

**结果定位：可运行的实验性移植，不是已验证的不可压缩求解方案。**
尽管平均体积误差较小，局部单元的体积变化仍很大，不能用平均 J 接近 1 来代替局部误差检查。
此外，附件直接复用 tau 的量纲与速度—压力速率形式不配平，详见 README_GLS.md。
本次保留附件形式，没有未经说明地改系数、加增强项或做无量纲化。

## 确认 GLS 实际开启

另做同空间、同时间离散的 3 步无稳定化对照，最后一步 t=0.015 s：

| 诊断 | GLS 开启 | GLS 关闭 |
|---|---:|---:|
| Galerkin 压力残量范数 | 3.3006e-07 | 3.3360e-16 |
| 候选 PSPG 项范数 | 3.3006e-07 | 1.6465e-06 |
| 总残量范数 | 1.7737e-11 | 5.2966e-11 |

关闭模式只计算候选 PSPG 诊断，不将其加到方程。开启后 Galerkin 压力项不再单独为零，和 PSPG 一起平衡。这确认了分支与残量接入，不构成长期压力稳定性证明。

## 文件与复现

- `vtk/gls.pvd`：本次完整周期主结果。ParaView 打开后用 displacement 做 Warp By Vector，比例 1。
- `source/solidmechanics_gls.py`：新求解器。
- `source/run_gls_vtk_cycle.py`、`source/run_gls.sh`：运行及增量导出。
- `source/verify_gls_results.py`：独立验证，运行 `python source/verify_gls_results.py .`。
- `source/environment-linux-64-explicit.txt`：现有环境的可复现版本清单。
- `diagnostics/no_stabilization_short/`：仅 3 步的关闭 GLS 对照，不是另一个完整周期。
- `input_reference/`：本次上传的两份原始代码，字节内容未改；仅作公式对照，原代码依赖的其他辅助模块未包含。
- `logs/`：实际运行日志；原运行环境的 MPI 硬件探测告警不影响随后完成的单进程计算。

此前 P2/P1 增强拉格朗日结果与本次在空间阶次、时间离散、约束残量和稳定化方式上均不同，不能视为仅开关 GLS 的对比。
